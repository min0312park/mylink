# MyLink 사용자 시나리오 (User Scenario)

## 페르소나 (Persona)
* **이름:** 지윤 (20대 후반)
* **직업:** 일러스트레이터 겸 인스타그램 크리에이터
* **니즈(Needs):** 인스타그램 프로필에는 링크를 하나밖에 걸 수 없어, 팔로워들을 자신의 유튜브 채널, 노션 포트폴리오 갤러리, 굿즈 판매 스토어 등 다양한 곳으로 유도할 수 있는 깔끔한 단일 링크 페이지가 필요하다.

---

## 시나리오 흐름

### 단계 1: 인지와 가입 (Onboarding)
1. 지윤은 동료 작가의 인스타그램 프로필에서 `mylink.com/@artist_kim` 이라는 주소를 발견하고 접속해 본다.
2. 깔끔한 링크 모음 화면에 반한 지윤은 자신도 만들기 위해 MyLink 랜딩 페이지에 접속한다.
3. 복잡한 폼 입력 없이 **구글 계정으로 로그인(소셜 로그인)** 버튼을 클릭해 10초 만에 회원가입을 마친다.
4. 자신의 고유 프로필 주소를 `mylink.com/@jiyoon_draws`로 설정한다.

### 단계 2: 프로필 및 링크 세팅 (Configuration)
1. 로그인 후 나타난 **어드민 대시보드**의 좌측 패널에서 자신의 대표 일러스트를 프로필 이미지로 업로드한다.
2. 이름에 '일러스트레이터 지윤', 소개글(Bio)에 '따뜻한 일상을 그립니다 🎨'라고 적는다. (입력과 동시에 우측 모바일 미리보기 화면에 즉시 반영된다.)
3. **링크 추가** 버튼을 누르고 자신의 굿즈 스토어 URL과 '굿즈 스토어 놀러가기'라는 타이틀을 입력한다.
4. URL을 입력하자마자 시스템이 **구글 파비콘 API**를 통해 스토어의 파비콘 아이콘을 자동으로 불러와 링크 버튼 좌측에 앙증맞게 표시해 준다.
5. 연이어 포트폴리오 노션 주소와 유튜브 채널 주소도 추가한다.
6. 유튜브 영상보다 굿즈 판매가 지금 더 중요하다고 판단한 지윤은, 링크 목록을 **드래그 앤 드롭**하여 굿즈 스토어 링크를 가장 위로 끌어올린다.

### 단계 3: 디자인 커스터마이징 (Customization)
1. 상단의 '디자인 설정' 탭으로 이동한다.
2. 여러 가지 **단색(Solid Color) 배경** 팔레트 중, 자신의 일러스트 톤과 가장 잘 어울리는 '파스텔 옐로우'를 클릭한다.
3. 우측의 실시간 미리보기 목업 화면의 배경이 예쁜 노란색으로 변경된 것을 확인하고 매우 만족해한다.

### 단계 4: 공유 및 분석 (Sharing & Analytics)
1. 세팅이 완벽히 끝난 것을 확인한 지윤은 상단의 '내 링크 복사' 버튼을 눌러 `mylink.com/@jiyoon_draws` 주소를 복사한다.
2. 자신의 인스타그램 프로필 수정 화면으로 이동해 해당 주소를 웹사이트 란에 붙여넣는다.
3. 며칠 뒤, 지윤은 다시 MyLink 대시보드에 접속한다.
4. 상단 통계 영역에서 내 페이지에 총 **1,500명의 방문자(조회수)**가 발생했음을 확인하고, 링크 통합 효과를 체감하며 미소를 짓는다.
