# MyLink (링크 트리 클론) 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요
**MyLink**는 사용자가 여러 링크를 하나의 통합된 페이지로 모아 공유할 수 있게 해주는 링크 관리 서비스입니다. 소셜 미디어 프로필, 포트폴리오, 비즈니스 페이지 등에서 단일 링크를 통해 팔로워들을 다양한 채널로 유도하는 것을 목적으로 합니다. 직관적인 UI/UX를 제공하여 누구나 쉽게 자신만의 링크 페이지를 구축하고 꾸밀 수 있습니다.

## 2. 핵심 기능 목록
1. 사용자 인증 및 계정 관리
2. 사용자 프로필 설정
3. 링크 관리
4. 페이지 디자인 커스터마이징 (단색 배경 변경)
5. 퍼블릭 공유 페이지
6. 기본 분석 통계 (방문자 수 조회)

## 3. 각 기능의 상세 설명

### 3.1. 사용자 인증 및 계정 관리
- **회원가입/로그인:** 이메일 및 비밀번호, 또는 소셜 로그인(구글, 카카오, 깃허브 등)을 통한 인증.
- **비밀번호 재설정:** 이메일을 통한 비밀번호 찾기 및 재설정 기능.
- **계정 설정:** 고유한 사용자명(URL 경로에 사용, 예: `도메인.com/username`) 설정 및 계정 정보 관리 기능.

### 3.2. 사용자 프로필 설정
- **프로필 이미지:** 이미지 업로드 및 크기 조절/크롭 기능.
- **프로필 정보:** 프로필 제목(이름) 및 짧은 자기소개(Bio) 작성.

### 3.3. 링크 관리
- **링크 추가:** 접속할 URL 및 링크 타이틀(버튼에 표시될 텍스트) 입력. (구글 API를 활용하여 입력된 URL의 파비콘을 자동으로 불러와 링크 아이콘으로 표시)
- **링크 수정/삭제:** 등록된 링크의 정보(URL, 타이틀) 수정 및 삭제.
- **링크 재정렬:** 드래그 앤 드롭(Drag & Drop)을 통한 링크 노출 순서 변경.
- **활성화/비활성화:** 링크를 삭제하지 않고 임시로 방문자에게 숨기거나 보이게 하는 토글 스위치 제공.

### 3.4. 페이지 디자인 커스터마이징
- **배경 설정:** 제공되는 단색(Solid Color) 컬러 팔레트 중에서 배경색 선택.

### 3.5. 퍼블릭 공유 페이지 (Public Page)
- **반응형 웹:** 모바일, 태블릿, 데스크탑 등 다양한 디바이스 환경에 최적화된 레이아웃 제공 (모바일 중심 설계).
- **링크 접속:** 방문자가 버튼 클릭 시 설정된 URL로 이동 (새 창 또는 현재 창).

### 3.6. 기본 분석 통계 (Analytics)
- **조회수:** 프로필 페이지 총 방문자 수 집계 및 표시.
